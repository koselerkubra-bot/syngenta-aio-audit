Creating a token (one-time, ~2 minutes):
  1. On GitHub, go to Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Under "Repository access", choose "Only select repositories" and pick koselerkubra-bot/syngenta-aio-audit.
  3. Under "Permissions", set Actions to "Read and write". Leave everything else as-is.
  4. Generate the token and copy it (it's only shown once). Paste it above.

You need to be a collaborator on the repository for this to work. If you're not sure, ask whoever manages it to add you under Settings → Collaborators.
